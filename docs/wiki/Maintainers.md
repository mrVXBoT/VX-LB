# نگهداری، اعتبارسنجی و انتشار Wiki

منبع قابل بازبینی راهنما در `docs/wiki/` مخزن اصلی است. همان Markdownها با پسوند `.md` در مخزن قابل خواندن‌اند؛ هنگام انتشار Wiki، پیوندهای داخلی به URL بدون پسوند تبدیل می‌شوند. از محتوای inventory یا credential برای تولید راهنما استفاده نمی‌شود.

## بازتولید مرجع‌ها

از ریشهٔ checkout با Python 3.10+ و Node.js اجرا کنید:

```bash
python3 scripts/generate_wiki_reference.py
python3 scripts/generate_wiki_reference.py --check
python3 scripts/publish_wiki.py
```

دو صفحهٔ مرجع قابلیت‌ها و فیلدها و `catalog.json` بازتولید می‌شوند. بررسی coverage، همهٔ گزینه‌های فعلی منوی موتور/پروفایل را با صفحات خانواده تطبیق می‌دهد. اگر گزینه‌ای اضافه شد، توضیح کاربرد، تنظیمات، محدودیت و خطای آن را نیز در صفحهٔ خانواده بنویسید؛ صرف اضافه‌شدن به snapshot کافی نیست. کامنت‌های `profile:` برای تطبیق ماشین‌اند و در نمایش معمول دیده نمی‌شوند.

مرجع قابلیت‌ها بین گزینهٔ رجیستری، گزینهٔ قابل انتخاب و وضعیت unsupported تفاوت می‌گذارد. مقدار پیش‌فرض یک رجیستری را بدون بررسی به فرم تعمیم ندهید. قابلیت نسخه‌های جدید upstream را تا ادغام و آزمون، قابلیت پنل معرفی نکنید.

## پیش‌نمایش بدون شبکه

```bash
python3 scripts/publish_wiki.py --output /tmp/vxlb-wiki-preview
```

این فرمان فقط صفحات آمادهٔ GitHub Wiki را در مقصد می‌نویسد. JSON کاتالوگ منبع توسعه است و صفحهٔ Wiki نیست. فایل خروجی را برای بررسی لینک‌ها بخوانید؛ چاپ پوشه به معنی انتشار نیست.

## انتشار در GitHub Wiki

GitHub Wiki مخزن Git جداگانه‌ای با نشانی `https://github.com/mrVXBoT/VX-LB.wiki.git` دارد. اگر هنوز صفحه‌ای ساخته نشده، ابتدا در رابط GitHub یک صفحه با عنوان **Home** بسازید و ذخیره کنید. تا قبل از این کار ممکن است clone با Repository not found شکست بخورد؛ فعال‌بودن تب Wiki به معنی ساخته‌شدن مخزن آن نیست.

بعد از آماده‌شدن Wiki، با حساب دارای اجازهٔ نوشتن و احراز هویت Git عادی اجرا کنید:

```bash
python3 scripts/publish_wiki.py --publish
```

اسکریپت صفحات آماده را اضافه/به‌روزرسانی و یک commit معمولی push می‌کند؛ force push یا حذف صفحات دیگر انجام نمی‌دهد. برای GitHub CLI می‌توان قبلاً `gh auth setup-git` را با حساب خود انجام داد. توکن را در URL، فایل راهنما یا خط فرمان عمومی قرار ندهید. توکن workflow عادی `GITHUB_TOKEN` را به‌طور پیش‌فرض دارای دسترسی Wiki فرض نکنید.

اگر دسترسی مستقیم Wiki فراهم نیست، نسخهٔ داخل مخزن قابل استفاده است؛ انتشار آنلاین را موفق گزارش نکنید. اصلاحات راهنما در مخزن اصلی باید از مسیر معمول بررسی تغییرات عبور کنند؛ انتشار Wiki با ادغام کد برنامه یا نصب روی سرورها یکسان نیست.
